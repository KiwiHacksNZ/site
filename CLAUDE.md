## Agent skills

### Issue tracker

Issues live in the KiwiHacksNZ org repos and on org project 3, and are created through the `dev-create-github-issue` skill (wayfinder maps are the one exception, and always live in the public `KiwiHacksNZ/site` repo). See `docs/agents/issue-tracker.md`.

### Triage labels

The five triage states are Status options on org project 3 (the source of truth), mirrored as labels on `KiwiHacksNZ/site` only; `bug` and `enhancement` are the category labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, created only when needed. See `docs/agents/domain.md`.
